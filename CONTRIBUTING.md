# Contributing

1. Branch from `main` using `feature/<short-name>` or `fix/<short-name>`.
2. Keep each pull request focused on one phase or behavior.
3. Use Conventional Commits such as `feat:`, `fix:`, `test:`, and `chore:`.
4. Run `npm run check` before opening a pull request.
5. Do not include credentials, connection strings, certificates, or updater private keys.

The `main` branch should require a pull request and successful CI checks.
